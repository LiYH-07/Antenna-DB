### 中華電信 Band 篩選

選取頻段後，系統將依以下頻點範圍進行比對，**僅顯示天線頻段範圍有重疊的項目**，展開的頻段規格表也只列出符合該頻段的列。

| 頻段 | 頻點範圍 (MHz) | 制式 |
|------|--------------|------|
| L900 | 940 – 960 | LTE |
| L1800 | 1820 – 1870 | LTE |
| N1 | 2150 – 2170 | NR |
| L2600 | 2640 – 2690 | LTE |
| N78 | 3420 – 3510 | NR |

> ℹ️ 篩選邏輯：天線的 `SubBand_Low_MHz` ≤ 頻段上限 **且** `SubBand_High_MHz` ≥ 頻段下限，即視為符合。

## 天線涵蓋計算器

「地面涵蓋」模式下，輸入天線型號、天線高度 H<sub>t</sub>、用戶高度 H<sub>r</sub>、總下傾角（機械＋電子）後，顯示：

- **涵蓋模擬圖**：鐵塔側視示意圖，畫出 0° 水平線、主瓣（下傾角）、垂直波束寬（VBW）上下緣、近端／遠端半徑與主瓣落點。
- **頻段切換**：模擬圖上方的頻段 chip（LB / MB / HB…）或點選下方結果表任一列，即切換為該頻段的 VBW、增益、H-BW 重新繪製。
- 若中華電信 Band 篩選啟用，計算器只列出符合該頻段的列。
- 波束上緣 (θ−VBW/2) ≤ 0° 時遠端顯示 ∞ 並提示加大下傾角。

> 模擬圖垂直方向已放大以便辨識，圖上角度為示意；距離標示為實際計算值。

### RSRP 估算（COST-231 Hata／3GPP 38.901）

在「地面涵蓋」模式粗估用戶實際收到的 RSRP。輸入項目：

| 分類 | 參數 | 輸入方式 | 預設／來源 |
|------|------|---------|-----------|
| 頻譜 | 電信業者 | 選單 | 中華（試算表 `電信頻寬`） |
| 頻譜 | LTE Band／頻段編號 | 選單（B8-B2、B3-C2…；天線未涵蓋的頻段會停用） | 自動選天線涵蓋的第一個頻段 |
| 頻譜 | DL 中心頻率、頻寬、PRB | 自動帶入 | `電信頻寬`（5G n78 依 SCS 30 kHz 由頻寬換算 PRB） |
| 發射端 | 每 Port 發射功率 | 手動 | 46 dBm |
| 發射端 | MIMO 配置 | 選單（1／2／4／8 × Port） | 2 × Port；只影響顯示的總發射功率，**RSRP 以單一 Port 計，不隨 MIMO 增加** |
| 發射端 | CRS Boost | 手動 | 0 dB |
| 天線 | 天線增益 | 頻段查表 | 同一頻段有多列時只取一列（完整涵蓋 DL 頻段者優先，再取最窄的一列） |
| Cable | Cable 尺寸、長度 | 選單／手動 | 1/2、7/8、1-5/8（`單位損耗表`）；30 m |
| Connector | 數量、單一 Loss | 手動，附快選 | 4 個；0.1 dB/個（`單位損耗表`） |
| Cable | N78 | 勾選 | 預設**不計** Cable／Connector（AAU 主動天線），勾選後才計入 |
| 傳播 | 傳播模型 | 選單 | COST-231 Hata（預設）／3GPP 38.901 UMa／UMi／RMa |
| 傳播 | 環境（Hata）／視距（38.901） | 選單 | 都會／NLOS；RMa 另有平均建物高度 5 m、街道寬度 20 m |
| 用戶端 | 穿透損耗 | 手動，附快選 | 室外 0／汽車 8／室內 15／高鐵車廂 25 dB |
| 用戶端 | 人體損耗 | 手動 | 3 dB |
| 用戶端 | 涵蓋機率、陰影標準差 σ | 選單／手動 | 90%；σ 依模型自動帶入（Hata 8、UMa NLOS 6、UMi NLOS 7.82、RMa NLOS 8、LOS 4 dB），可修改 |
| 用戶端 | 實測校正 | 手動 | 0 dB（實測 − 估算） |
| 其他 | 其他附加損耗、植被損耗 | 手動 | 0 |
| 結果 | RSRP 門檻 | 手動 | −95 dBm |

計算方式：

```
RS 功率 = 每 Port 功率 − 10·log10(12 × PRB) + CRS Boost
Cable 損耗 = 單位損耗 × 長度 + Connector 數 × 單一損耗 + 其他附加損耗
RSRP（中位數）= RS 功率 − Cable 損耗 + 天線增益 − 場型衰減 − 路徑損耗 − 植被 − 穿透 − 人體 + 實測校正
RSRP（涵蓋機率）= RSRP（中位數）− 陰影餘量
```

結果顯示計算過程、**RSRP vs 距離**曲線（實線為涵蓋機率 RSRP、虛線為中位數），以及各頻段近端／主瓣落點／遠端的 RSRP 與最大涵蓋距離（以涵蓋機率 RSRP 判斷）。

- Cable 單位損耗依頻率落在 `單位損耗表` 哪一列的頻率範圍取用；不在任何範圍內時取最近一列，相差超過 300 MHz 時依 √f 外推並標示。
#### 3GPP TR 38.901 傳播模型

依 TR 38.901 Table 7.4.1-1（f<sub>c</sub> 單位 GHz、距離 m）；NLOS 取 max(LOS, NLOS′)：

| 模型 | 適用 | LOS（斷點 d<sub>BP</sub> 前／後） | NLOS′ |
|------|------|------|------|
| UMa | 都會宏站，典型天線 25 m，10 m–5 km | 28 + 22·log d<sub>3D</sub> + 20·log f<sub>c</sub>／28 + 40·log d<sub>3D</sub> + 20·log f<sub>c</sub> − 9·log(d′<sub>BP</sub>² + (h<sub>BS</sub>−h<sub>UT</sub>)²) | 13.54 + 39.08·log d<sub>3D</sub> + 20·log f<sub>c</sub> − 0.6(h<sub>UT</sub> − 1.5) |
| UMi 街谷 | 街道微站，典型天線 10 m，10 m–5 km | 32.4 + 21·log d<sub>3D</sub> + 20·log f<sub>c</sub>／32.4 + 40·log d<sub>3D</sub> + 20·log f<sub>c</sub> − 9.5·log(…) | 22.4 + 35.3·log d<sub>3D</sub> + 21.3·log f<sub>c</sub> − 0.3(h<sub>UT</sub> − 1.5) |
| RMa | 郊外宏站，天線 10–150 m，10 m–10 km（NLOS 5 km） | 含平均建物高度 h、斷點後 +40·log(d<sub>3D</sub>/d<sub>BP</sub>) | 含街道寬度 W、建物高度 h |

- UMa／UMi 的有效環境高度 h<sub>E</sub> 簡化取 1 m。
- 38.901 適用 0.5–100 GHz（RMa 0.5–30 GHz），短距離與 3.5 GHz（n78）的估算比 Hata 合理；超出距離範圍的部分在圖上標示為外推。

- Hata：1500 MHz 以下用 Okumura-Hata，以上用 COST-231 Hata（大都會 +3 dB）；郊區、鄉村依 Hata 修正式扣減。
- 頻段選「不指定」時，頻率取天線子頻段中心（啟用中華電信 Band 篩選時取該頻段中心），PRB 由「頻寬」選單決定。
- 垂直場型衰減依 3GPP 近似 12·(偏離主瓣角 / VBW)²，上限 20 dB，所以塔下附近會出現低谷。
- **樹林區（植被損耗）**：Hata 沒有樹林類別，另外加植被損耗，從接收電平扣除，最大涵蓋距離同步縮短。有兩種方式：
  - **固定值**：直接輸入 dB（快選：疏林 5／樹林 10／密林 15）。樹林區常用約 8–15 dB。
  - **樹林深度模型**：輸入信號穿過樹林的深度 d（m），依各頻段頻率計算，所以高頻段損耗較大：

    | 模型 | 公式 |
    |------|------|
    | Weissberger | d ≤ 14 m：0.45·f<sup>0.284</sup>·d；14 < d ≤ 400 m：1.33·f<sup>0.284</sup>·d<sup>0.588</sup>（f 單位 GHz） |
    | 早期 ITU-R | 0.2·f<sup>0.3</sup>·d<sup>0.6</sup>（f 單位 MHz） |
    | FITU-R 有葉 | 0.39·f<sup>0.39</sup>·d<sup>0.25</sup>（f 單位 MHz） |
    | FITU-R 落葉 | 0.37·f<sup>0.18</sup>·d<sup>0.59</sup>（f 單位 MHz） |

    深度超過 400 m 時標示為外推：實際上信號會改走越過樹冠的繞射路徑，損耗趨於飽和，模型會高估。台灣常綠林多數時間適用「有葉」。

  兩種方式都建議以實測校正。

> 模型適用範圍：150–2000 MHz、天線高度 30–200 m、用戶高度 1–10 m、距離 1–20 km。超出範圍（例如 3.5 GHz、1 km 以內）會標示為外推，結果僅供參考。未計陰影衰落餘量與穿透損耗。

### 反推下傾角

在計算器輸入「目標涵蓋距離」後，會算出達到該距離所需的總下傾角：

| 方式 | 公式 | 用途 |
|------|------|------|
| 主瓣對準 | θ = atan(ΔH / D) | 主瓣剛好打在目標距離 |
| 上緣對準 | θ = atan(ΔH / D) + VBW/2 | 波束上緣落在目標距離，涵蓋不越過 D，常用於控制越區干擾 |

- ΔH = 天線高度 − 用戶高度。上緣對準依各頻段 VBW 分別計算，並列出對應的近端距離。
- 對照 `Electrical_Tilt_Range_deg`：超出上限時提示需補多少機械下傾。
- 按「套用」即把該下傾角填回計算器，模擬圖同步更新（下傾角取到小數一位，遠端距離會與目標略有差異）。

### 高處涵蓋（大樓／高架橋／山坡）

計算器上方切換到「高處涵蓋」，再選目標類型。三種類型都用同一套算法：目標視為一段距離與高度都可能不同的線，計算波束涵蓋其中哪一段。

| 類型 | 輸入 | 目標線 |
|------|------|--------|
| 🏢 大樓 | 大樓距離、大樓高度、每層樓高 | 垂直的大樓立面，結果換算成樓層 |
| 🌉 高架橋 | 天線方位角、橋面高度（相對天線地面）、用戶高度，加上兩端點（距離＋方位）或中心＋走向 | 水平的橋面（用戶高度），可任意轉向 |
| ⛰️ 山坡 | 天線基地海拔、山腳距離／海拔、目標距離／海拔、用戶高度 | 從山腳到目標的斜坡，結果附海拔 |

- **涵蓋區段與比例**：波束（俯角 θ−VBW/2 ~ θ+VBW/2）落在目標線上的區段，以及佔整段的比例；整段都沒照到時，會指出目標在波束上方或下方。
- **兩端衰減**：目標兩端偏離主瓣的角度，以及依 3GPP 垂直場型近似 12·(Δθ/VBW)²（上限 20 dB）估算的衰減。
- **上仰**：下傾角可輸入負值（例如 −5 = 上仰 5°）。
- **高架橋的方位（水平角）**：以天線實際射向（方位角，正北順時針）換算橋相對天線的位置，所有方位都用正北順時針 0–360°，可直接用 Google Earth 尺規量測（距離與 Heading）：
  - **兩端點**：從基地台量到橋段起點、終點的距離與方位。
  - **中心＋走向**：橋中心的距離與方位、橋走向（起點往終點的方位）、橋長。
  - 橋上每一點同時計算相對天線的方位偏角與俯仰偏角，衰減 ≈ 12·(方位偏角 / H-BW)² + 12·(俯仰偏角 / VBW)²，上限 25 dB（3GPP 場型近似），−3 dB 以內視為涵蓋；H-BW 取自試算表 `Horizontal_BW_deg`。
  - 模擬圖為**俯視圖**（上方為正北、依實際比例），可直接對照地圖：天線射向與 H-BW 扇區、橋面高度上的 −3 dB 涵蓋範圍、橋與被涵蓋的橋段。
  - 反推另列出「方位對準橋段中心」要向左／右轉幾度、建議的方位角，以及橋段水平張角（需要的 H-BW）。
- **反推**：主瓣對準起點、主瓣對準終點、置中涵蓋整段（並列出所需 VBW，表格標示各頻段 VBW 是否足夠）；按「套用」填回計算器。

> 未考慮中間地形或建物遮蔽。上仰通常需要機械或支架調整，多數天線的電下傾不支援負角度。

## 軌道沿線：洩波電纜與軌旁天線

計算器上方切換到「軌道沿線」，再選「洩波電纜」或「軌旁天線」。

### 洩波電纜

型號清單只列出 `Antenna_Band_Spec` 備註中有衰減與耦合損耗的電纜（另有「自訂」可手動輸入）。頻譜、發射端、Cable／Connector（饋入跳線）與用戶端損耗沿用路徑損耗的設定。

| 輸入 | 預設 | 說明 |
|------|------|------|
| 電纜長度、饋入方式 | 500 m、單端 | 雙端饋入時兩端同功率；同一 Cell 以功率相加，不同 Cell 取較強者（不做功率合成） |
| 電纜高度、用戶高度 | 2.5 m、2.5 m | 高鐵沿線電纜與車窗同高 |
| 電纜到用戶的水平距離 | 6 m | 快選：靠窗 3／走道 4.5／對側 6 m |
| 規格範圍取值 | 中間值 | 「~」範圍取中間值或上限（保守） |

```
RSRP = RS 功率 − 饋入損耗 − 縱向衰減 × 距饋入點長度 − 耦合損耗 − 20·log10(d / 2 m) − 穿透 − 人體 + 實測校正
```

- 電纜規格從備註解析，格式為「Attenuation 2.1~2.2 dB/100m; coupling loss (2 m) 50% 78~79 dB, 95% 88~89 dB」；新增其他洩波電纜時照這個格式寫在 Notes 即可。
- 耦合損耗依 IEC 61196-4 在 2 m 量測，距離不同時以 20·log10(d/2) 修正。**95%（設計值）與 50%（中位數）同時計算並列出**：沿線圖實線為 95%、虛線為 50%，示意圖、計算過程與各頻段表格也都同時列出兩者；兩者都不另扣陰影餘量。
- 結果：
  - **系統架構與訊號路徑**：BBU → RRU／Repeater → Jumper／接頭損耗 → 饋入點 A ═ LCX（縱向衰減 α）═ 饋入點 B ← RRU／Repeater ← BBU；單端饋入時末端接終端負載。下方列出饋入點與最弱點（雙端在中點、單端在末端）的 95%／50% RSRP。
  - 沿線 RSRP 圖下方有**列車位置條**：電纜與饋入點，列車預設停在最弱點，手指或游標移動時跟著走並顯示該位置 RSRP（軌旁天線模式同樣有，改標天線位置）。
  - 沿線 RSRP 圖（標出饋入點）、饋入點與最差點 RSRP、單端最大涵蓋長度，以及同業者各頻段一覽。
  - 這裡的「饋入點 RSRP」是站在該位置、車廂內用戶收到的 RSRP，不是電纜內的信號功率。

### 軌旁天線

一般板狀天線裝在軌道側邊（高約 2.5 m，與車窗同高），沿軌道照射。天線清單列出非洩波電纜的天線，增益、H-BW、V-BW 取自 `Antenna_Band_Spec` 涵蓋所選頻段的那一列。頻譜、發射端、Cable／Connector 與用戶端損耗沿用路徑損耗的設定。

| 輸入 | 預設 | 說明 |
|------|------|------|
| 計算路段長度 | 500 m | 沿軌道里程 0 到 L |
| 天線高度 h<sub>ant</sub>、用戶高度 h<sub>UE</sub> | 2.5 m、2.5 m | |
| 橫向距離 D<sub>perp</sub> | 6 m | 天線到用戶（軌道中心）的橫向距離 |
| 天線位置與指向 | A1 0 m →、A2 500 m ← | 可新增／刪除；指向為往里程增加或減少 |
| 下傾角 θ、朝軌道偏角 φ<sub>0</sub> | 0°、0° | 同高時下傾約 0 |
| 其他附加損耗 L<sub>misc</sub> | 0 dB | 橋墩、隔音牆等 |

```
d(x)     = √(x² + Dperp² + (hant − hUE)²)
RSRPi(x) = RS 功率 + G − 場型衰減(φ, θ) − 饋線 − FSPL(d) − 穿透 − 人體 − Lmisc + 實測校正
服務電平  = max_i RSRPi(x)（不同 Cell 不做功率相加）
```

- FSPL = 20·log10(d) + 20·log10(f MHz) − 27.55，假設視距。
- 場型用 3GPP 近似：水平 12(φ/H-BW)²、垂直 12(θ/V-BW)²，合計上限 25 dB（背向即以 25 dB 近似前後比）。
- 結果：俯視示意（軌道、各天線位置與波束扇形、最弱點）、沿線 RSRP 圖（細線各天線、粗線服務電平）、最弱點與服務天線的計算過程、涵蓋比例，以及同業者各頻段一覽。

## 常見問題

**Q：網頁顯示「無法載入資料」？**  
A：檢查兩點：① SHEET_ID 是否正確貼上；② Google Sheets 是否已完成「發佈到網路」的步驟。

**Q：資料沒有更新？**  
A：Google Sheets 發佈的 CSV 可能有幾分鐘延遲，按網頁右上角「⟳ 重整」並稍等。

**Q：中華電信 Band 篩選後沒有顯示天線？**  
A：表示目前資料庫中無天線的頻段範圍涵蓋該中華電信頻段，請確認 Google Sheets 的 `SubBand_Low_MHz` / `SubBand_High_MHz` 欄位已正確填寫。

**Q：可以設定密碼保護嗎？**  
A：GitHub Pages 本身不支援密碼。若需要，可以改用 Cloudflare Pages + Access 或改 Private repo + GitHub Pro。
